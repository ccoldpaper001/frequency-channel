# 文字论坛（Supabase 版）

一个可以注册、登录、发帖、删除自己帖子的论坛，使用 Supabase 免费云数据库，无需自己的服务器。

## 文件说明
- `index.html` —— 页面结构
- `style.css` —— 样式
- `app.js` —— 论坛逻辑（登录/注册/发帖/删除）
- `supabase-config.js` —— Supabase 连接配置（**需要你自己填**）

---

## 第一步：注册 Supabase 并创建项目

1. 打开 https://supabase.com ，用 GitHub 或邮箱注册（免费）。
2. 点击 **New Project** 新建项目：
   - Name 随便填，比如 `forum`
   - Database Password 自己设一个并记住
   - Region 选离你近的（如 Singapore / Tokyo）
3. 等待 1~2 分钟项目创建完成。

## 第二步：创建数据表

进入项目后，点击左侧 **SQL Editor**，新建查询（New query），把下面的 SQL 全部粘贴进去，点 **Run** 执行：

```sql
-- 帖子表
create table posts (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now() not null,
  user_id uuid references auth.users(id) on delete cascade not null,
  author_nickname text,
  title text not null,
  content text
);

-- 开启行级安全（RLS）
alter table posts enable row level security;

-- 所有人（包括未登录）都能看帖子
create policy "帖子对所有人可见"
  on posts for select using (true);

-- 只有登录用户能发帖，且 user_id 必须是自己
create policy "登录用户可以发帖"
  on posts for insert with check (auth.uid() = user_id);

-- 只有帖子作者能删除自己的帖子
create policy "只能删除自己的帖子"
  on posts for delete using (auth.uid() = user_id);
```

## 第三步：关闭邮箱验证（可选，方便测试）

默认注册后需要去邮箱点确认链接。测试阶段建议先关闭：

1. 左侧 **Authentication** -> **Sign Up / Providers**
2. 把 **Confirm email** 开关关掉
3. 点 Save

（正式上线时建议再打开）

## 第四步：填入配置

1. 左侧齿轮 **Project Settings** -> **API**
2. 复制 **Project URL** 和 **anon public** key
3. 打开本文件夹里的 `supabase-config.js`，分别粘贴到两个引号里，保存。

## 第五步：运行

直接双击 `index.html` 用浏览器打开即可使用。

> 如果浏览器提示跨域问题，可以用 VS Code 的 Live Server 插件打开，或在文件夹里运行：
> ```
> npx serve .
> ```
> 然后访问它给出的地址（如 http://localhost:3000）。

## 功能
- ✅ 邮箱注册 / 登录 / 退出
- ✅ 发表文字帖子（标题 + 内容）
- ✅ 帖子按时间倒序展示
- ✅ 只能删除自己的帖子（数据库层权限控制）
- ✅ 内容做了 HTML 转义，防止 XSS
