网络故障排查

Q: 无法连接 API，提示 Failed to fetch？

A: 可能原因和解决方法：

1. 网络限制：OpenAI 等国外 API 需要特殊网络环境，建议使用国内 API 服务（DeepSeek、通义千问、智谱AI 等）

2. 防火墙拦截：Windows 防火墙可能拦截了本地端口，启动器已尝试自动添加防火墙规则，如失败请手动允许端口

3. CORS 跨域限制：某些 API 服务不允许浏览器直接调用，这是 API 服务器的限制，需要联系 API 提供商

4. API 地址错误：检查地址是否正确，是否已包含 /v1 路径（可在设置中取消自动添加 /v1）

推荐国内 API 服务：

• DeepSeek：https://api.deepseek.com/v1

• 通义千问：https://dashscope.aliyuncs.com/compatible-mode/v1

• 智谱AI：https://open.bigmodel.cn/api/paas/v4

小功能
